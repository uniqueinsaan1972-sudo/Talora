# Changelog
## 0.7.1 (free Gemini option for DAGORUNA)
Added: the assistant can use Google Gemini (free tier from Google AI Studio) instead of Anthropic. Set GEMINI_API_KEY (optional GEMINI_MODEL, default gemini-2.5-flash). Provider choice: Gemini if GEMINI_API_KEY exists, otherwise Anthropic if ANTHROPIC_API_KEY exists, or force with AI_PROVIDER=gemini|anthropic. Provider errors are logged on the server (status and first 300 characters, never the key) to help debugging in Vercel logs. Privacy note added to the assistant settings.
Verified (run): `tsc --noEmit`, `next build`, and the route test (16 checks for Gemini, 15 for Anthropic) against mock servers: auth, validation, key sent only server-side in the right header, request shape (Gemini systemInstruction and user/model roles), language hints, daily quota, not configured.
NOT verified: a real Gemini call (no key was available): the default model name and your key's free quota must be checked in AI Studio.
## 0.7.0 (DAGORUNA voice assistant)
Added: floating DAGORUNA button (right side, above the bottom bar, hidden on the landing page and during a Mega Test) that opens a chat panel: type or use the microphone, answers shown on screen and spoken, Stop and Replay, speed Slow/Normal/Fast, voice on/off, text-only mode, microphone-language choice, microphone permission status, Clear, minimise, remembered settings and last 20 messages (on this device). Mascot states idle/listening/thinking/speaking/error use the existing artwork poses with light CSS animation and an animated waveform. Welcome message in English, Urdu and Hindi.
Added: "Ask Dagoruna" on every word card and flashcard in Word practice: opens the assistant with the word loaded and sends the 12-point word explanation (meaning, Urdu, Hindi, definition, pronunciation, part of speech, 3 examples, synonyms, antonyms, usage, level, practice question), plus quick actions: More examples, Make a sentence, Pronounce, Explain in Urdu / Hindi, Test me.
Added: secure server route /api/dagoruna (Anthropic API, key only in server environment variables): requires a logged-in Supabase user, validates input, 8 requests/minute burst limit, daily quota in the database (migration 0008, default 100/day), 25 s timeout, friendly error messages in the learner's language. The system prompt limits the assistant to English learning and tells it to answer in the learner's language (Roman Urdu is answered in Urdu script).
Verified (run): `tsc --noEmit`, `next build`, 35 shared unit tests (language detection, input validation), SQL smoke test including the quota, and an end-to-end test of the route against MOCK Supabase and MOCK AI servers (401 without or with a bad token, 400 for bad input, 200 reply, API key sent only server-side, language hint en/ur/hi in the prompt, 429 over quota, 503 when not configured).
NOT verified: real AI answers (no API key was available), voice input/output in real browsers, Android Chrome or the installed TWA, mobile layout of the panel.
## 0.6.0 (TALORA 2.0, first slice: Mega Test and result reports)
Added: TALORA Mega Test at /exam: short (10), standard (up to 20) and comprehensive Mega (48) tests; six levels (Beginner to Expert Challenge); timed or untimed; 48-question bank (vocabulary, grammar, sentence formation, translation Urdu/Hindi/Roman Urdu to English, spelling, reading, listening via browser text-to-speech); multiple choice, fill in the blank, word arrangement; randomised selection without repeats inside a test; skip, previous/next and jump-to-question.
Added: grading on the server (migrations 0006 and 0007): answer keys are hidden from the browser, duplicate or unknown questions are rejected, XP for exams is capped at 10 per day. Each attempt is saved to the user's account.
Added: result report at /exam/report/[id]: score ring, correct / incorrect / skipped, time, accuracy, per-skill bars, strongest and weakest skill, suggested level (rough guide), next steps, mistakes with corrections, comparison with the previous test of the same length in percentage points (shown only when a previous test exists), Retake, Share (device share sheet or copy), Download as PDF (device print dialog, Save as PDF).
Added: dashboard "Latest Mega Test" card and button, Progress page test history and 30-day XP chart, Practice hub entry.
Verified (run): `tsc --noEmit`, `next build`, routes respond 200 locally, 32 shared unit tests (exam selection, scoring helpers), SQL smoke test of migrations 0001-0007 including exam grading (all correct = 100%, partial with skipped and wrong, duplicates / unknown / too few questions rejected, clients cannot read answer keys).
